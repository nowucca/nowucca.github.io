  1. 2026-11-14R076Graphify: a tree-sitter code graph that agents query instead of grepBuilds a persistent local graph of a folder: code parsed by tree-sitter (~40 languages, no LLM), audio/video via local faster-whisper, docs/PDFs/images via LLM subagents emitting JSON fragments. Every edge is EXTRACTED (1.0), INFERRED (0.95 to 0.55) or AMBIGUOUS; Leiden clustering finds subsystems without embeddings; NOTE/WHY comments and ADR citations become rationale nodes; SHA256 cache for incremental rebuilds. Queries: query (2,000-token budget, depth 2), path (rated by weakest hop), explain; MCP server, git hooks, `graphify prs` impact and merge-order risk. A Claude Code PreToolUse hook steers Grep/Read to the graph, with a strict mode that blocks reads until the graph was queried. Self-reported: LOCOMO recall@10 0.497 (mem0 0.048) but QA 45.3% vs supermemory 49.7%; LongMemEval-S ties dense RAG at 76%; 71.5x fewer tokens per query on 52 files, ~1x on 6. Caveats: "no LLM" holds only for code; static parse misses dynamic dispatch; memory benchmarks, not code tasks; open core (verification, cross-repo in paid cloud).
