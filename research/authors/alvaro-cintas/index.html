  2. 2026-11-16R097MiniMind: the whole LLM training pipeline at 64M parametersOne readable script per stage on a Qwen3-style 64M decoder (8 layers, d768, GQA, 6,400-token vocab; a 198M-A64M MoE too): tokenizer, pretrain, SFT with tool calls mixed in and an open_thinking template switch, hand-written LoRA, DPO, PPO with GAE, GRPO, CISPO, multi-turn agentic RL (488-line train_agent.py: up to 3 tool turns, six mock tools, trajectory reward from answer, tool count, format, reward model and unfinished penalty, clipped to [-3, 3]; rollout engine split torch/sglang) and white-box distillation; open data for every stage, exports to transformers, llama.cpp, vLLM, Ollama. Best lessons: reward sparsity and degenerate GRPO groups at small scale (watch reward variance), judge rewards drift from environment rewards, RL costs general ability, exam-format LoRA adds about 2.9 points. Caveats: data heavily distilled from Qwen3/R1, Chinese-first, tools are mocks, transformers still used for tokenizer/base class/reward model, single-author repo with breaking reorganisations.
