  1. 2026-11-24R255talabat: fit the store to the data, with a four-phase shadow migrationIsolating eight country stacks would have multiplied relational cluster costs, so talabat asked which datasets were actually relational. Carts and orders are aggregates read and written whole, so each became one DynamoDB item holding snapshots of values it doesn't own, re-validated at checkout; per-request billing removes the per-market cost floor, with a reported 70 to 90% storage cost cut. The migration ran in four phases (abstraction, dark build, dual-write shadow with background comparison, cohort rollout), graduating only on days of near-zero mismatches. An AI agent now drafts storage recommendations and migration plans for human review.
