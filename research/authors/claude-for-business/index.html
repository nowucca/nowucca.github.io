  1. 2026-11-23R229sharedWarp's self-improving agents: feedback becomes a reviewed skill editEach Warp agent (PR review, issue triage, spec writing) runs a base skill. A scheduled improver skill pulls human feedback from PR and issue comments, compares the agent's output with how people reacted, and opens a PR with the smallest edit to the base skill; a human reviews and merges. Advice: principles not rules, explain why, capture feedback where work happens, keep skills small, don't conflate skills with memory, assume feedback is sometimes wrong. Gaps: no before/after quality numbers, no replay or regression check before merge, no pruning.
