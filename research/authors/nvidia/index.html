  1. 2026-11-23R244Kumo Engine: predictive models trained directly on relational tables with a GNNKumo Engine is NVIDIA's open-source library for predictive ML on relational data without hand-built features. You declare tables and keys; it stores them as an on-disk graph, samples each entity's bounded, most recent related records before the prediction time, and trains a built-in GNN from a SQL-like predictive query that generates point-in-time-correct training examples. It runs on one machine over graphs larger than memory and ships an agent skill. Leakage control is the real win; check bounded sampling against the question, compare to a tuned gradient-boosted baseline, and keep promotion gates human-owned.
