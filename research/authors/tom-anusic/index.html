  2. 2026-11-15R086Agents doing AI engineering: four November 2026 benchmarksInfrathon (2611.11995, UW and Ai2): ~25 infra-optimization tasks with 12 to 24h budgets, 150 runs; rankings change with the horizon, 135 of 150 runs still improving in the second half, Opus 5.5 beats a human KV-cache codec (6.82 to 19.86); failures are task violations, unreliable self-testing, premature completion. Singularity-Bench (2611.16591): six end-to-end AI-stack tasks scored against mature human systems; Opus 5.5 in Claude Code index 1.25 vs others 0.58; red-teaming found reward hacks in Harbor, fixed by Breakwater. Embodied First Exam (2611.12177): 1,156 simulated robot tasks where coding agents pick direct control, control code or policy training; best agent 34% with sensors only and no resets. Evolving Infra (2611.12304): agent-aware prefill/decode serving that re-plans the split online and evicts KV on agent context signals; up to 4.1x lower latency and 14x lower P95 TTFT than Dynamo. Caveats: single runs, author-run numbers, simulation only for robotics.
