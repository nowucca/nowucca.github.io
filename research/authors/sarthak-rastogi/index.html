  1. 2026-11-16R099Evaluating agents at Amazon: three layers, traces and humans in the loopAmazon's framework for thousands of internal agents: a four-step workflow over offline or online traces (metrics, S3 or dashboard, degradation alerts, scheduled human audits) and a metric library in three layers: outcome (goal success, correctness, helpfulness, safety), components (intent, tool selection vs parameter accuracy vs call error rate vs call sequence, memory retrieval, topic adherence, grounding and reasoning faithfulness) and model (benchmarks for quality, latency, cost). Cases: shopping assistant (cross-org tool schema and description standards, LLM-generated tool specs, golden regression sets synthesized from API logs), customer-service orchestrator (intent routing tested with LLM-simulated personas on anonymized query/intent pairs), seller assistant multi-agent (planning, communication and collaboration-success scores, human review of coordination). Caveats: no validity or before/after numbers, metric list is mostly AgentCore Evaluations' catalog, LLM-synthesized and LLM-judged throughout, the post's 'replay traces against new versions' is not in the article, recovery is named but not measured.
