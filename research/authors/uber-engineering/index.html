  1. 2026-11-23R246Uber's skills marketplace: evals, ablation and agent-filed papercutsUber runs one Git-backed marketplace of more than 5,000 agent skills serving Claude Code, Codex, Cursor and internal agents, with over a million invocations a month. Around it: three tiers with rising bars, one CLI that translates skills into each agent's config, OpenTelemetry per-skill metrics, spec-first authoring with a linter, eval suites mixing golden, trajectory-graded and human-judged cases, and with/without ablation against a noise band. Cost levers include Code Mode scripts, cheaper worker subagents and load-time scripts, and an always-on skill lets agents file their own papercuts. Open problem: evaluating rare, high-stakes workflows.

  2. 2026-11-13R071Uber's MCP Gateway: turning 10,000 services into agent toolsRegistry (control plane) plus proxy gateway (data plane). AutoCrawler, a Cadence workflow on the IDL registry, generates virtual MCP servers and tools from Protobuf/Thrift with LLM-written descriptions; the gateway translates JSON to HTTP, gRPC or TChannel. Tool-level authorization by caller type (human, service, agent) and built-in PII redaction. Context controls: Omni MCP (discover_server, discover_tools, get_tool_schema, invoke_tool), GraphQL-like response projection, and Code Mode via the aifx CLI writing results to files (now the default for coding agents). 800+ servers, 5,000+ tools. No latency or quality numbers.
