  1. 2026-11-23R235Streaming LLM tokens from a managed JVM Lambda: SSE without a custom runtimeOn the managed Java Lambda runtime a RequestStreamHandler's output is buffered until the handler returns, so LLM tokens arrive all at once. An MIT library's core module writes API Gateway's streaming wire format through a 1 MB buffer, lifting the 6 MB response limit to 200 MB; its experimental SSE module posts a chunked response to the Runtime API via a Java agent, keeping the managed runtime and SnapStart, so Bedrock tokens start arriving at about 3% of total response time. Limits: undocumented runtime internals, API Gateway REST only, 2 MB/s after 6 MB, billing continues after client disconnect.
