  1. 2026-11-24R256OntoBricks: an ontology over live warehouse tables, served to agents over MCPOntoBricks, a Databricks Labs project, puts an OWL ontology on top of Unity Catalog tables instead of copying data into a separate graph database: LLM-assisted ontology design and SQL mappings compile to R2RML, triples are views over live tables (or a Lakebase snapshot or Neo4j), OWL 2 RL, SWRL and SHACL compile to SQL, and each domain publishes chosen MCP tools plus GraphQL and read-only SPARQL. Versioned domains have a draft, review and publish lifecycle, and MCP tools run as the end user. Key caveat: freshness is per path, since SPARQL reads current rows while MCP lookups use snapshot indexes.
