  1. 2026-11-23R248Exact: Expo's all-platform app framework built around the agent loopExact is Expo's new open-source (MIT, pre-1.0) app framework: one source tree builds native apps for web, iOS, macOS, Linux and Android, designed so a coding agent can build, run, see and test the app through one deterministic loop. A small typed UI language compiles to a plan run by a Rust VM over real native widgets; one driver exposes the same ten operations (tree, screenshot, tap, clock and so on) on every host, with a driven clock so tests never sleep; one verify command checks themes, widths, accessibility and text scaling. Tradeoffs: immaturity, no React or Flutter plugin bridge, a new language, and driver-observed behavior that can hide real-device bugs.
