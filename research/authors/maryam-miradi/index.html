  3. 2026-11-15R08315 building blocks of agent memory, checkedTypes (working, episodic, semantic, procedural, long-term), mechanisms (summarization, retrieval, consolidation, compression, graph memory) and control (decay, forgetting, conflict resolution, provenance, isolation). Repo fit graded per pattern: 6 good, 3 partial, 5 weak, 1 wrong (DSPy for conflict resolution); AutoGen is in maintenance mode, Letta's source moved to letta-code, and Graphiti is the better link for conflict resolution and provenance. Corrections: the groups mix content type, lifetime (working = context window), data model (graph) and write-path loss (summarize, consolidate, compress are one evidence-discarding decision; R059); decay and forgetting are one policy, separate from verifiable deletion; conflict resolution needs source and validity time. Trend: mem0 v3 went ADD-only with time-aware retrieval, matching R040/R057's append-only evidence. Missing: admission policy (store only verifiable facts), scope and expiry at write time (the one-off address test), memory poisoning, gain/regression vs no-memory and raw-history baselines, cost, multi-writer merge, user correction. Adds a five-stage pipeline (admit, record, derive, retrieve, govern) with a test per stage, failure modes and a review checklist. Caveat: a course funnel; 400+ agents claim unverified.

  4. 2026-11-15R07915 agent design patterns, checked for teachingTiers: single agent (ReAct, plan-and-execute, reflection, tool use), multi-agent (orchestrator-subagent, supervisor, hierarchical, sequential pipeline, fan-out/fan-in, MapReduce, debate) and feedback loops (evaluator-optimizer, critic-actor, self-healing retry, human in the loop). The value is the reading list (ReAct, Plan-and-Act, Reflexion, Gorilla, AutoGen, AgentOrchestra, LLMCompiler, Multiagent Debate, Self-Refine, CRITIC, a CHI 2025 plan-then-execute study); citation fit is graded per pattern (a survey stands in for two, one paper is reused twice). Corrections: five patterns are one produce-check-revise loop that differs only in what grounds the check (self, another model, a tool or test, a human), and self-review without an outside signal is unreliable; three are one delegation tree; the first split is code vs model owning control flow, not agent count; multi-agent pays for context isolation and parallel breadth, not load. Missing: routing, gated prompt chains, handoff, shared state, durable execution, action guardrails, memory. Adds a decision order, failure modes per tier, a review checklist and a 60-minute session plan. Caveat: a course funnel; the 400+ agents claim is unverified; link rather than copy the graphic.
