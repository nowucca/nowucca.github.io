  1. 2026-11-22R226sharedJetriever: rank every agent memory by usefulness, not similarityJetriever skips the similarity shortlist: a small LLM-derived decision model scores every stored memory for the probability it helps answer the query. On InMind's 125 indirect queries it ranks the gold memory first 84.8% of the time (BM25 1.6%, MiniLM 0%) and reaches 76% end-to-end application against at most 16% for published systems, near the 84% oracle. A general 9B model recognises as many gold memories in its top 50 but only 40% at rank 1: calibration, not recognition, is the hard part. Cost grows linearly with the pool.
