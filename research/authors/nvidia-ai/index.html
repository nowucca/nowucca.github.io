  3. 2026-11-18R148Nemotron-Labs-Sigma: continuous diffusion language models with a built-in drafterTokens become learned points on a 16-D unit sphere; the model denoises Gaussian-corrupted 32-token blocks on a KV-cached prefix, warm-started from a 1T-token AR checkpoint (+300B tokens).   4. 2026-11-11R030OpenShell: kernel-enforced sandboxes and verified policy for AI agentsA runtime for agent fleets: a gateway control plane, and per sandbox a split across a trust boundary, with the sandbox side owning the agent's processes and intercepting TCP and DNS (Landlock, seccomp user notification, no capabilities) and a trusted supervisor deciding every request, resolving DNS and injecting credentials only for approved endpoints (agents see placeholders). The supervisor channel is the only egress; the agent cannot start until the boundary is confirmed and freezes if it drops. An SMT-based prover runs a boundary check (does a policy exceed an environment's maximum, with counterexamples; usable by a parent agent on a subagent's policy) and a proposal risk check on agent-requested network rules (new credentialed hosts, new methods, metadata endpoints), blocking auto-approval. Caveats: guarantees only cover what the prover models (not MCP or GraphQL rules), allowed access can still be misused, approval fatigue, 0.1.x and mid-move to CNCF, telemetry on by default.
