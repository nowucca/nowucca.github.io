  1. 2026-11-21R213sharedZed Delta: review the agent thread, not the pull requestZed's Delta (public beta) makes the agent conversation thread the unit of collaboration and review instead of the pull request. Teammates join a thread, ask the same agent why it chose something, and review in subthreads with isolated worktree copies whose fixes fold back before landing. DeltaDB records edits between commits beside the messages that caused them, while staying Git-compatible. Tradeoffs: longer narratives to read, lock-in of the narrative, and review gates to re-express without PRs.

  2. 2026-11-12R034AG-UI: an event protocol between agents and user-facing appsThe agent-to-user slot beside MCP (tools and data) and A2A (agent to agent): an agent run as a typed, transport-agnostic event stream (SSE, WebSocket, webhook) of lifecycle, streamed text and tool-call args, state snapshots plus JSON Patch deltas, reasoning (summaries or encrypted), sub-agents, and runs that end in success or an interrupt. Builds up to shared read-write state, frontend-executed tools, generative UI the app validates before mounting, and human-in-the-loop pause/approve/edit. Middleware adapts native framework events; wide support (LangChain, CrewAI, Microsoft Agent Framework, Google ADK, AWS Strands and AgentCore, Mastra, Pydantic AI, Claude Agent SDK, OpenAI Agents SDK) and about ten language SDKs. Caveats: delta gaps silently corrupt client state, shared state needs real conflict resolution, frontend tools widen the trust boundary, Raw/Custom events erode portability, spec still moving, vendor-hosted services sit beside the protocol.
