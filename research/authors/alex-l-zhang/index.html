  1. 2026-11-24R258Harnesses as compositional generalizers: RLMs keep every model call in distributionAn MIT CSAIL paper argues that Recursive Language Model (RLM) harnesses, which keep task data in a program environment and split work into sub-calls, keep each model call locally in distribution as tasks grow. Per the abstract, RLMs trained with RL only on short tasks generalize to tasks 2 to 64 times longer, training transfers across domains with shared structure, and RLM-27B (trained on synthetic surrogate environments) improves Qwen3.8-27B in the same harness by 26.9% on average on hard long-context suites with about 2x fewer inference tokens. Key caveats: controlled benchmarks and few base models, slower training per sample, and no production cost or latency data.
