  1. 2026-11-16R110harness-profiler: a profiler for Claude Code skill and agent factoriesAsync, fail-open Claude Code hooks (PostToolUse, SubagentStop, compaction) append one JSON line per call to `.harness-profile/<session>.jsonl`; an offline `tree` links calls to contexts by agent id (not by time) and draws a UML sequence diagram, one bar per context (main, fresh subagent or forked skill, or copy of the parent), inline skills as diamonds, with new, cached and output tokens per context from the transcripts. Works on the web by committing the hook via `init`. The case study: a "final" validation reran the Rails review, tests and lint after only Markdown changed (up to 60 s and 48k new tokens per change, both runs PASS), because uncommitted code broke a git-keyed reuse rule. Encode a healthy trace as a `check-trace` skill. Caveats: undocumented transcript format, inline skills not separable as cost, Bash-mediated file work hides Reads/Edits, Codex unsupported, traces hold tool arguments; built-in OpenTelemetry tracing beta (per a commenter) may cover fleet use.
