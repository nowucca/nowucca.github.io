  4. 2026-11-17R120nanochat: the whole LLM pipeline in one hackable repoMinimal single-node harness: BPE tokenizer (32,768 vocab), pretraining (Muon + AdamW, FP8), SFT on SmolTalk + MMLU aux x3 + GSM8K x4 with a Python tool, RL, CORE and bits-per-byte evals, KV-cache inference, chat CLI. Reference speedrun beats GPT-2 CORE (0.2565) in 1.65 h on 8xH100 (~$48), down from 3.04 h in Jan 2026; ClimbMix data and two autoresearch rounds drove the biggest gains. Distinctive ideas the post skips: one `--depth` dial sets every hyperparameter compute-optimally and changes must help at all depths; a public time-to-GPT-2 leaderboard with commits; explicit precision instead of autocast; no config framework; PRs disclose LLM-written code. Post overstates "understand RoPE, GQA" (code implements, Discussions guides teach) and omits the 8xH100 cost. Data mix: one pretraining dataset; SFT mix via epoch flags or editing chat_sft.py. Caveats: speedrun data ratio 8 is tuned to the leaderboard, SFT on MMLU/GSM8K train flatters those evals, from-scratch only.

  6. 2026-11-15R082Craft Anything: rebuild software, graded against the originalA desktop app, CLI and MCP server around a pure-Rust reverse-engineering engine (320 tools: decoders, disassembler, decompiler, optional Ghidra) driving a coding agent (Claude Code first; others via ACP, mostly unverified). Loop: Study the target (website, app, game, file), Build a new project in the requested stack, Check against the original (websites at three widths, games by their own self-test, apps by running them) and refine until Ready. The original is the oracle; findings are evidence records with confidence, coverage, limitations and an unknowns list; open questions live in an `inbox/` folder. Clean room (default) refuses tools that read code or files, explicitly a tool policy and not an OS sandbox; Deep unlocks everything. Caveats: similarity is UI fidelity, not correctness (auth, races, business rules); clean-room leakage via the agent's own shell; IP risk is the user's; installs run code; alpha, two weeks old, 33K stars.

  7. 2026-11-12R052Open Code Review: Alibaba's hybrid AI code reviewerPlain code does file selection, bundling of related files into isolated-context sub-agents, template-matched review rules, and separate comment positioning and reflection; the agent only reads code, searches for context and reasons about defects, with a toolset distilled from production tool-call traces. Delegation mode hands the model half to the host agent (Claude Code, Codex, Cursor and others). On Alibaba's AACR-Bench (200 PRs, 1,505 labelled issues), OCR + Opus 4.6 scores F1 25.1% and precision 33.9% vs Claude Code + Opus 4.6 at 11.6% and 7.2%, at about 1/15 of the tokens; recall is lower (20.0% vs 28.9%), and with Opus 4.8 OCR recall falls to 11.7%. Caveats: vendor-built benchmark, untuned baselines, old OCR versions in the table, low absolute scores, rule and bundle boundaries narrow what gets seen.
