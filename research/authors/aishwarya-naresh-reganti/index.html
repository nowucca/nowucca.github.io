  1. 2026-11-17R121Harness²: self-improving harnesses without a ground-truth verifierFrozen executor, eight editable harness files (prompt, guardrails, memory, skills, tool guidance, scripts, subagents, middleware). Per task, a contrastive Propose-Probe-Compose step: run once as reference, draft an invariant and a domain-scoped candidate, run both under matched conditions, compose a successor from behavioral contrasts with no ground-truth verifier; afterwards an improvement library keeps the adopted harness plus an evidence-backed EXPERIENCE.md, and each new task starts from the base harness. One step: GLM-5 on WorkBuddy 64.2 to 75.7 (beats stock Gemini 3.5 Flash), LAB +11.8 pp; parallel k=5 adds 3 to 7; fewer execution steps; scoping is the biggest ablation (-2.9/-3.7); editing blind drops WB-Code 73.4 to 63.2. Reganti's critique: evaluator shares the executor's blind spots, and it edits its own guardrails, so propose offline, regression-gate, review, stage and roll back.

  2. 2026-11-11R026HybridAgent: agents that think in latent space and act in textInside one generation the agent switches between text and latent steps, where a small residual adapter (HybridLink, about 10M parameters at 4B) feeds the hidden state back as the next input with no decoding; tool calls and answers stay in text, and the KV cache carries text, latents and tool results across turns. Trained from Qwen3-Base (4B to 14B) by hybrid SFT with self-conditioning, then RL whose policy factorizes over text positions with exact latent replay. Versus matched text agents: 35.5% to 54.7% fewer tokens, 1.8× to 2.6× faster, about 10% more accurate after RL; 14B scores 52.4 on GAIA vs 43.7 for same-backbone ARPO. Latents read back as approximate pseudo-text and visible-trace monitoring holds up. Caveats: needs open weights and a custom serving stack, the KV cache becomes the only copy of session state, and pseudo-text approximates the computation.
