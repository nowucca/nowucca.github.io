  1. 2026-11-25R303What does the system do when the model is wrong, or gone: gates for AI-drafted regulatory reportsA reference architecture for drafting suspicious activity reports — formal filings a regulated financial institution sends to law enforcement, which must be factually correct and meet a deadline — with a language model in the loop. Read it for the structure, not for evidence: the article states its architectures are representative rather than deployed, and it reports no measurements of any kind. The framing is the useful part. Two assumptions sit under most systems we build: a correct component produces correct output, and it keeps behaving that way until somebody changes it. A model breaks both, so the question stops being what the model can do and becomes what the system does when the model is wrong, or gone. The pipeline runs a pre-built event knowledge graph, a query planner that halts the automation entirely and says so rather than drafting when data is missing, a reranker, a drafter citing source identifiers against a defined schema, a judge stage pairing deterministic checks with an independent model judge, and a coordinator that publishes to risk-tiered human review — with reviewers' own edits evaluated too, so a reviewer cannot quietly introduce an unsupported statement. The strongest section is the release gates: version the model, prompts, retrieval logic, data mappings, policies and eval set, each with an owner; test with deterministic factuality checks and jurisdiction-specific regressions; shadow and canary against the incumbent; monitor reviewer edit rate as the leading indicator, because reviewers absorb degradation before factuality failures appear; and roll back through configuration flags not to a previous model version but to <em>more human involvement</em>, ending at the fully manual process. A system that can degrade to the thing it replaced is one you can actually switch off under regulatory pressure. Three gaps to fill if you adopt this: the judge is version-pinned but never validated against human labels, so a frozen judge applies its blind spot to every release; scores are combined by averaging, which lets a factuality miss be offset by good tone when factuality needs a veto; and no numeric threshold is given for any gate or rollback trigger, which leaves the gates advisory.
