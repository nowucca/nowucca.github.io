  1. 2026-11-22R220Accept agent code on evidence, not line-by-line reviewTwo practitioners converge: Paul Iusztin says reading every line of agent code is mostly wasted effort and acceptance should rest on criteria, tests, static, type and security checks, and realistic runs; Matt Pocock says TDD's ritual matters less for agents but the evidence matters more, asking for a test that fails without the change and passes with it, and warns of tautological tests. The reviewer's job shifts to auditing evidence, with line review triggered by risk, novelty or a failed check.
