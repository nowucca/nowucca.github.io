  1. 2026-11-23R243Shirudo: agent-written eBPF shields that hold the line until the patch landsShirudo is an open-source Linux runtime from OpenAI and Cisco for temporary, targeted mitigations: signed eBPF shields that attach to a live process or kernel hook and block an exploit's code path while the real patch rolls out. Agents investigate the vulnerability, draft a shield and test it against the exploit and representative traffic; operators approve deployment, and a TPM records loads and removals. In a demo, a Codex-written shield blocked a Java4Shell attempt in a running Elasticsearch without downtime. The engineering questions are validation coverage, the verifier proving safety rather than correctness, shield expiry and hot-path overhead.
