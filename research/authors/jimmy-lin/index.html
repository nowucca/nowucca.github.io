  1. 2026-11-25R297Keep the frontier model in charge, give the legwork to a small local oneCascades and routers decide which model runs a whole task, which means the cheap model gets the wheel and the task is lost when it is out of its depth. This harness takes the opposite arrangement: the frontier model leads every task start to finish and never hands over control, delegating only <em>subtasks</em> — reading code, running tests, searching a corpus — to subagents running a small model on hardware you already own. No router, no model trained, either side swappable. Frontier cost falls to a third of baseline on long-horizon coding and to 41% on agentic search, with the number of tasks solved unchanged; a 2B model that fits on a laptop does nearly as well on coding as a 27B one. The explanation is better than the result. The coding harness already spawned subagents by default — it just spawned them on the frontier model, on 98% of the hardest task set, accounting for 53% of its cost — so moving that work explains 80% of the saving. The remaining 20% is the lead model's own behaviour changing: 46–48 turns per task instead of 84, its own test runs dropping from about eight to one or two, and 11–24% less tool output reaching its context because only reports return rather than raw output. A long agent trajectory is mostly not reasoning. The short delegation instruction is load-bearing, but not for cost: without it delegation still roughly halves cost and loses tasks, so the instruction is what protects task performance while the saving happens. Two cautions worth carrying: the saving is strongly lead-model-dependent — a plan-first frontier model reached only 69% of baseline rather than 34%, half the benefit from the same setup — and delegation makes tasks slower, a median 38 minutes instead of 25 on long tasks and roughly double on short ones, so this is a batch-mode optimisation. The search path's pattern generalises: make the cheap model's report checkable by construction, with quotes verified mechanically against their sources, rather than asking the expensive model whether it looks right.
