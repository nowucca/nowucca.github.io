  1. 2026-11-25R290Ask the environment, not the model: harness disciplines from a multi-agent systems book reviewA practitioner review of <em>Building Agentic AI Systems, Second Edition</em>, whose organising claim is that a model inside a loop is not a system: the system is the harness, the protocol layer, the deployment and the controls. The most transferable idea is reinjection — when the model announces it is finished, the harness runs a verifier it already trusts and feeds the failure text back as the next observation, because a model's self-report of completion is a generated token sequence with no privileged access to the world. If you cannot name the cheapest check you actually trust for a task class, you do not have a termination condition, you have a stopping heuristic. Three more disciplines: diagnose whether the model ever received the instruction before rewriting the prompt, since plumbing failures misdiagnosed as reasoning failures produce long superstitious prompts; write error messages for the model, giving the actionable delta rather than a stack trace; and mark every synchronous edge between agents, because chained agents reproduce the distributed monolith. Key caveat: none of these come with effect sizes — they are engineering heuristics with good mechanical justification, not measured results.
