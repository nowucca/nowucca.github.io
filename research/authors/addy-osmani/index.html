  1. 2026-11-21R214sharedClaude Code Code Mode: the agent writes a script instead of calling tools one at a timeAn experimental Claude Code mode where the model writes a short JavaScript program, run through a REPL tool, that makes many tool calls itself: in parallel, chained, and filtered so only what matters reaches context.
