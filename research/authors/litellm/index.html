  1. 2026-11-24R254LiteLLM agent_eval: score harness-plus-model setups on your own tasksLiteLLM's preview agent_eval API makes the (harness, model) pair the unit you compare: declare tasks with predicate, LLM-judge or command checks once, list targets such as Claude Code, Codex or your own agent with models routed through a LiteLLM gateway, and get one scorecard of pass rate, cost and duration per target. Errors and timeouts count as failures, a run passes only if the agent stops with done and the check passes, each attempt gets a fresh symlink-free workspace, and agent and judge spend are separate. Caveats: small task sets can't rank close setups, changing harness and model together confounds results, and the API is unreleased.
