  2. 2026-11-13R073Twelve open-source repos for securing AI-written codeA layered list: rules and LLM review at PR time (Semgrep, Claude Code Security Review), whole-repo agent audits (Cloudflare's skill, Codex Security), exploit-proving pentest agents against the running app (Strix), known-vuln and infra scanners (Nuclei, Trivy), secrets (TruffleHog), malware (ClamAV), skill scanning (SkillSpector), LLM-app red-teaming (PyRIT) and anti-AI-reverse-engineering (BLA).   3. 2026-11-12R037Floorplan: a generated map as a fix for comprehension debtFiled as a foil to comprehension debt. A Claude Code / Codex plugin: dependency-free Node scripts scan repos for imports, endpoints and outbound requests and match requests to endpoints across repos; the model then names and describes every part, file and endpoint in plain words, and a build step adds a Health check (keys in code, open Supabase/Firebase, fakeable Stripe webhooks, unauthenticated endpoints), screens, a "Recent work" board and a local single-file HTML map with an Ask bar. Refresh re-reads only files whose content or signature changed; a PRD mode draws a blueprint before code exists. The scripted half shrinks comprehension debt because it is checkable; the model-written half moves the debt from the code to the map: descriptions go stale when only bodies change, scripted and model-added edges look the same, the agent explains its own changes, and "understand it without reading the code" can make the debt feel paid.
