Corrections

  • "Multi-agent orchestration" mixes three things. CAMEL and MetaGPT are multi-agent simulations; Atomic Agents is a component library; Burr is code-owned control flow for one app (closer to durable workflows, R015/R079 territory). GPTSwarm is a paper's code.
  • "Memory & reasoning" holds one memory store and a half. mem0 and Letta are memory; DSPy optimises prompts and programs; STORM is an application that writes cited reports.
  • "Autonomous builders" are coding agents from the 2024 SWE-bench wave. The coding agents teams run daily in 2026 (Claude Code, Codex CLI, Aider, Cline, OpenCode, Goose) are absent; only OpenHands and SWE-agent are still central.
  • "Total cost: $0.00" is not true in use. Model tokens dominate cost; E2B, Composio and Skyvern have paid hosted tiers; AGPL (Skyvern) and a custom license (Agent Zero) carry legal cost.
  • Stars are not fitness. Devika (19.5k) and Plandex (15.9k) out-star half the active entries and are stale.

Missing layers

  • Agent frameworks most production code uses: LangGraph, OpenAI Agents SDK, Pydantic AI, Google ADK, CrewAI (R081 lists these).
  • Durable execution: Temporal, Restate, Inngest, or LangGraph checkpoints (R094).
  • Evals: Inspect AI, promptfoo, DeepEval (R099, R107).
  • Tracing on OpenTelemetry: Langfuse, Arize Phoenix, OpenLLMetry, instead of a vendor-only SDK.
  • Protocols: MCP SDKs and servers, A2A (theme 6.4).
  • Sandboxes beyond E2B: Daytona, gVisor/Firecracker-based runners (R093).
  • Guardrails and policy: action allowlists and an MCP gateway (R071); interpreter-level sandboxes (R061).

Review checklist for picking from a list like this

  1. Last push and last release within 90 days; open-issue response time.
  2. Canonical repo: follow redirects and pin the new owner.
  3. License fits how you ship (AGPL, custom, "source available").
  4. Who owns control flow: your code or the model. Prefer code when the steps are known.
  5. Traces export to OpenTelemetry.
  6. Sandbox and permission story for any tool that runs code or a browser.
  7. An eval hook: can you run the same task suite before and after an upgrade?
  8. Exit path: what breaks if the project stalls (Devika, Plandex).
