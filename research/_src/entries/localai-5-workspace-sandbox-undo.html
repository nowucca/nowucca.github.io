What it is

LocalAI began in 2023 as a drop-in OpenAI-compatible API for open models. It is now a self-hosted server that runs text, vision, image, video, music and speech models behind one API, answering in both the OpenAI format and the Anthropic format (/v1/messages). It has more than 80 backends (llama.cpp, vLLM, MLX, whisper.cpp and others), 18 of them native C/C++/GGML engines written by the project. Each backend is its own image, pulled only when a model needs it. It runs on CPU, NVIDIA, AMD, Intel, Apple Silicon, Vulkan and Jetson, with a distributed mode (PostgreSQL plus NATS) and P2P.

Design choices worth noting

  • Undo as a safety primitive. Every model-made file change lands in the same history as the user's own edits, so mistakes are reversible rather than prevented.

  • Permissions the model cannot touch. Sharing and access changes are reserved for a human in the browser. Agents and add-ons cannot grant or revoke access.

  • Network off by default. Sandbox and Pages start with no network, and a chat can request more but never exceed what an admin allows.

  • Honest limits in the release notes. Projects explicitly do not isolate files, and add-ons run as the server's OS user; only the Sandbox isolates.

Failure modes to watch

  • Add-on trust. Add-ons other than the Sandbox run with the server's OS privileges. A malicious or buggy add-on has full access.

  • Projects are not boundaries. A chat outside a project can still open its files; don't use Projects for confidentiality.

  • Chat-app bots. Slack and Discord add-ons answer nobody until senders are allowed; misconfiguring that exposes a saved agent.

  • Scheduled triggers spend tokens. Each run is a full chat turn on local hardware.

  • Small models on CPU are slow, which affects agentic features that chain many calls.

Review checklist for a self-hosted agent workspace

  • Which components isolate execution, and which run with server privileges?

  • Can the model change permissions or sharing? (It should not.)

  • Is every model action reversible, and is the history tamper-evident?

  • What is the default network posture for code execution?

  • Do the OpenAI- and Anthropic-format endpoints behave identically for tool calls?
