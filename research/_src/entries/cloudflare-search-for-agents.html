What it does

A zone-level toggle (dashboard Quick Actions or API) creates an AI Search instance for the site, crawls and indexes its pages, and exposes a search endpoint on the site's own domain. Access follows the zone's bot management, AI Crawl Control and WAF settings.

Interface

  • Endpoint: GET /.well-known/search?q={query}. The blog itself advertises https://blog.cloudflare.com/.well-known/search?q={query} in its head.

  • Discovery: HTML meta tags agent:instructions, agent:endpoint, agent:method and agent:documentation. The verbatim instruction: "Use this search API to find relevant content across this site with keywords or natural-language queries, instead of crawling individual pages. Results are returned in Markdown." With Markdown for Agents enabled and Accept: text/markdown, the same fields appear as YAML front matter under an agent: key.

  • Query: keywords or a natural-language question in q. The HTTP QUERY method is also accepted, with a plain-text or JSON {"q": ...} body.

  • Response: retrieved Markdown passages with source references and a score per result, not a generated answer, since the caller is assumed to have its own model.

Availability

All plans including Free, with limits; usage is billed as AI Search (ingestion, index storage, queries). The same instance can also back an MCP endpoint, a REST API, Workers bindings and a human search widget. The post does not state a re-crawl interval or freshness guarantee.

Engineering takeaways

  • This is a step from "make pages readable to agents" (Markdown for Agents) to "answer the agent's query on the site". For a small content site, a .well-known/search endpoint is cheaper for agent visitors than crawling.

  • The discovery convention is meta tags plus a well-known path, not llms.txt. Whether other hosts adopt agent:* tags is the open question.

  • Returning passages rather than answers keeps attribution and leaves reasoning to the caller, which suits agents that cite.

Caveats

Vendor launch post. No independent latency or quality data.
