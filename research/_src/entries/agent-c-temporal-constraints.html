Kamath, Zhang, Xu, Ugare, Singh and Misailovic (UIUC, with Meta), arXiv 2512.23738; code at structuredllm/agent-c.

Agent-C makes ordering and state policies hard constraints on tool calls, and does it cheaper than retrying. Policies like "authenticate before reading data" are written in a small DSL (Before, After, Forall, Exists, Seq, plus developer-written projection functions that read tool state). The DSL compiles to first-order logic; the trace so far plus the proposed call is checked with Z3.

Mechanism. With open weights, the tool call is generated under a tool-call grammar. On a violation the decoder backtracks to the last compliant argument boundary and resamples, so it never pays for a whole new turn. Closed APIs get a reprompting variant that resamples whole calls. If the iteration budget runs out, the agent emits an explicit error tool instead of acting.

Results. On tau-bench retail and airline, plus 17 adversarial variants of each written by the authors:

  • Claude Sonnet 4.5: conformance 77.4% to 100%, utility 71.8% to 75.2%. GPT-5: conformance 83.7% to 100%, utility 66.1% to 70.6%.

  • Adversarial harm 0%, against up to 29.4% unconstrained.

  • Qwen3-32B retail utility 53.3% versus 37.4% for AgentSpec and 9.6% for DynaGuard.

  • Backtracking ablation (Qwen3-8B retail): 42.1% utility versus 36.5% for reprompting, with 4,156 versus 5,437 input tokens and 359 versus 600 output tokens per call.

  • Latency cost: 480 s versus 333 s unconstrained on Qwen3-32B, so wall-clock rises about 44%.

Why it matters for efficiency. Enforcing inside decoding turns a rejected action from a full round trip into a partial resample. The utility gain says hard constraints also stop the agent from wandering into states it then has to recover from.

Caveats. Z3 and the projection functions are trusted, and someone must write them. Specs cannot refer to future states. Three trials only; the adversarial set is the authors' own. One utility figure in the body (80.5% for Sonnet) differs from the abstract's 75.2%, probably a different setting.
