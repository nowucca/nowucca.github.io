Source: Google Research blog, "Supercharging transformer residual connections" (Kyriakos Axiotis and Thomas Fu, 2026-11-23), on the ICML 2025 paper DeepCrossAttention (arXiv 2502.06785). Found via TLDR AI 2026-11-24.

What it is

A standard residual connection adds each layer's output to its input with a fixed weight of one. By depth 30, every earlier representation has been summed into one stream with equal weight. Features computed early get diluted, and later layers spend capacity recomputing them.

DeepCrossAttention (DCA) replaces that fixed sum with a learned router over the whole layer history:

  • Per-token layer weights. Each token gets its own mix of all earlier layer outputs. The weights are a learned static base plus an input-dependent projection. So the network can act sequentially (only use the last layer) or in parallel (pull from many) per token.

  • Depth-wise attention. Queries, keys and values are each built from separately weighted mixes of earlier layers. Normal attention runs across tokens; this runs across layers.

  • Safe initialisation. DCA can start out identical to a plain residual network, so it can be retrofitted onto a trained model.

Results the post reports

  • Same quality "up to three times faster", and "up to five times fewer training steps" on C4 and LM1B.

  • LM1B, perplexity under 14: the baseline needed 42 layers; DCA beat it with 30 (29% fewer layers and parameters).

  • Parameter overhead under 0.2%.

  • More layer history helps: perplexity 15.14 for the baseline down to 14.35 at k=24.

  • Retrofit: continued training of a pretrained transformer with DCA cut perplexity by 0.19, against 0.02 for plain continued training.

  • Baselines at equal parameter and training budgets: LAUREL-PA, 1x1-DenseFormer, Hyper-Connections.

What to be careful about

  • These are perplexity and step-count results on small LM benchmarks. The post shows no downstream task scores and no model sizes.

  • The "negligible" cost is in parameters. The post admits more memory bandwidth, because each layer reads many earlier activations, but gives no latency or memory numbers. For inference serving this is the cost that matters.

  • The "up to" figures are best cases.

  • The post says Thinking Machines' Inkling 2 adopted the design, with no source. Treat as unverified.

Why it matters for a staff engineer

Residual-stream design is now an active axis in frontier models: hyper-connections, Moonshot's attention residuals, and DCA all go after the same dilution problem. Tencent's Hy4 (R283) ships with 4-stream identity Hyper-Connections. If you serve or fine-tune open weights, expect architectures where activations from many layers stay live. That changes activation memory, KV-adjacent buffers and kernel fusion. The retrofit result also suggests that some of these gains can be had from continued pretraining of an existing model, not only from training from scratch.
