The argument

Read together, Microsoft's Ignite 2026 agent releases build a control plane for agents, including ones running on other vendors' platforms. Each control sits outside the agent, where the agent cannot see or argue with it.

Identity: Entra Agent ID for external agents (preview)

Agent 365 connects to another platform, syncs that platform's agents into its registry and issues each one a Microsoft Entra Agent ID, with no change to agent code. Named platforms include Salesforce Agentforce, Amazon AgentCore, Google Vertex AI, Databricks, Snowflake, Anthropic Claude Managed Agents, OpenAI, Oracle, SAP, ServiceNow and UiPath. Status is preview, "capabilities vary by platform", with rollout completing in December, so coverage on any one platform cannot be promised yet.

Once an agent has an identity, admins can apply supported Conditional Access policies, assess identity risk and revoke access. The connection uses workload identity federation, so there is no long-lived secret to rotate. The tools registry that inventories what agents use is GA.

Observability: external agents (GA)

Azure Monitor's observability and evaluation for agents hosted anywhere, including AWS and Google Cloud, is generally available. Builders send compatible traces to Application Insights and register the agent; registration does not instrument the agent or grant source access, which makes it usable across an organizational boundary. Cross-agent debugging that follows one request across agents and runtimes is still preview. Microsoft is moving its own agent products onto OpenTelemetry's GenAI semantic conventions, which makes the trace format closer to a contract than a feature.

Runtime controls in Foundry Agent Service

  • Network egress rules (GA): ordered allow/deny rules enforced outside the agent's sandbox, with an audit mode that logs what would have been blocked.

  • Scale (GA): shared subnet IPs lift a ceiling of roughly 250 concurrent sessions per /24 subnet; default quota 1,000 or 2,000 sessions per subscription by region.

  • Resilient execution (GA): recovery reruns your handler, so side effects must be idempotent; save progress as you go.

  • Toolboxes: a curated set of tools and skills behind one MCP endpoint that holds downstream auth, plus tool search to load definitions on demand.

  • Durable execution (GA) for Microsoft Agent Framework on Azure Functions, with zero-compute human approvals; the same scheduler backend carries LangGraph and Pydantic AI.

  • Retrieval permissions (GA): SharePoint, Entra group and storage permissions enforced under the caller's identity, including over MCP.

Where announcements outrun docs

The hosted-MCP connector announcement lists custom container images and a prebuilt Cosmos DB server in preview; the documentation page at the time listed only Playwright and Azure SQL and put custom images in the backlog. Some items are GA, more are preview, and at least one is announcement-only. Check each status line.

Tradeoffs

  • Cross-cloud governance vs. concentration. One identity plane across vendors simplifies policy and creates a single point of control and failure.

  • Agent-blind enforcement is robust against prompt injection but harder to debug when an agent fails because of a rule it cannot see.

  • OpenTelemetry alignment reduces lock-in at the trace layer even as identity deepens it.

Failure modes to watch

  • Preview coverage gaps leave some agents unidentified while dashboards look complete.

  • Non-idempotent handlers double-send emails or payments after recovery.

  • Egress rules in audit mode that never move to enforce.

  • Identity without least privilege: an Entra ID on an over-scoped agent is visible but not safer.

Review checklist

  • Which of your external agents actually have an identity today, per platform?

  • Are side effects idempotent under handler replay?

  • Are egress rules enforced, not just audited?

  • Can you trace one request across agents and vendors, or only within one?

  • Do retrieval permissions follow the end user, not the agent's service identity?
