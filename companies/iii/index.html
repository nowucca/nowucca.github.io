Company profile

iii (formerly Motia)

Researched 2026-10-29WebsiteLinkedInGitHub

Snapshot

iii is a very small (LinkedIn: 2–10 employees), US-based, apparently pre-revenue developer-infrastructure startup. It ships an open-core Rust "engine" that connects functions, agents, APIs, models, browsers and machines through three primitives (Function, Trigger, Worker), with SDKs for Node.js, Python, Rust and Go. It positions itself as "the engine beneath agent frameworks and workflow tools" and as self-hostable ("The convenience of a platform, without the lock-in"). It is the successor to Motia, the TypeScript backend framework that ranked #1 in the JS Rising Stars 2025 backend category; github.com/MotiaDev/motia now redirects to iii-hq/iii and motia.dev says "Motia is winding down. iii.dev is what's next." The engine and CLI use the Elastic License 2.0 (SDKs and docs use Apache 2.0), and a private-source iii-cloud CLI exists, so the likely business model is a hosted or managed cloud. No pricing or paid product is published yet.

Mission, purpose, vision, values

They don't publish a formal mission or values page. The closest things are the homepage and the manifesto (https://iii.dev/manifesto, "The iii manifesto: collapse the categories"):

  • "More application. Less infrastructure." (homepage tagline)
  • "software complexity continues to grow. remove it. add a worker." (manifesto)
  • "systems engineering is integrations." / "three primitives are enough." (manifesto)
  • "AI is the forcing function. simplicity beats complexity." (manifesto)
  • "software becomes unreasonably simple to create, extend, and modify." (manifesto, intended outcome)
  • "An architecture you own, not a vendor-locked platform." / "Code shouldn't care where code runs." (homepage)
  • LinkedIn tagline: "The Interoperable Invocation Interface" (which explains the name).

History

  • Founder/CEO: Mike Piccolo. He was previously co-founder and CTO of FullStack (FullStack Labs), a software consultancy with about 150 clients. He studied at San Diego State and went through a coding bootcamp (Founder's Code podcast ep. 25, 2026-02-13). No co-founders were found.
  • Motia (2024–2025): an open-source "unified backend framework" (APIs, background jobs, workflows and AI agents built on one "Step" primitive), with GitHub org MotiaDev located in the "United States of America". It got 13.8k stars and was #1 in JS Rising Stars 2025, Backend/Full-Stack.
  • Early 2026: Motia 1.0-RC moved its runtime onto the Rust-based iii engine (PkgPulse; the MotiaDev "motia-iii-example" repo is dated 2026-03-14).
  • Spring 2026: rebrand to iii. The blog starts 2026-04-28 ("The Harness Is the Backend"), and Signal Over Noise wrote "Motia Became iii" on 2026-06-14. The main repo was carried over, which is why iii-hq/iii shows about 18.9k stars.
  • Pivot in emphasis: from a JS backend framework to agent infrastructure (agent harnesses, sandboxes, "loop engineering").

Ownership and status

  • Private. No acquisitions or parent company found.
  • The legal entity is unclear. The site footer, privacy policy, Rust crate authors and CONTRIBUTING licence header name Motia LLC. The website's JSON-LD and blog metadata name "III, Inc." GitHub issue #2412 (2026-10-27) flagged the mismatch. It was closed as "fixed" in PR #2419 without saying which entity is the real one. A move from an LLC to a C-corp ("III, Inc.") would be consistent with raising venture money, but that's a guess.
  • Jurisdiction: not found. SEC EDGAR couldn't be checked from this session (sec.gov was blocked by the network policy). It's worth searching EDGAR for "Motia" and "III, Inc." for Form D filings.

Engineering

  • Stack: engine and CLI in Rust; SDKs in TypeScript/Node, Python, Rust and Go; config via worker-compose.yaml; worker registry at workers.iii.dev; Homebrew tap. The blog shows interest in libkrun-based sandboxes.
  • Open source: iii-hq/iii has about 18.9k stars, 1.3k forks, 2,196 commits on main and 28 open issues and 67 open PRs as of 2026-10-29. The org page shows the repo as updated 2026-08-18, but issue #2412 was closed on 2026-10-27 with a fix PR (#2419), so work is ongoing. There are 13 repos, including workers (99★), spec-forge (24★), oh-my-harness, skills-and-validation and the private-source iii-cloud-cli. Docs are versioned up to at least 0.22.
  • Blog themes (13 posts, Apr–Oct 2026): agent harnesses, "loop engineering", sandboxes, cost of running coding agents, comparisons with OpenCode and Claude Code, EU compliance. There are no launch, funding or hiring posts.
  • Open roles: none found (no careers page, no LinkedIn jobs surfaced).

Signals for a candidate

Green flags

  • Real developer traction: about 18.9k stars and #1 JS Rising Star for backend in 2025.
  • Rust engine plus multi-language SDKs, squarely aimed at agent infrastructure, which is a hot area.
  • The founder has run a consultancy before, and the team ships steadily (2.2k commits, frequent docs versions).

Red flags / risks

  • No public funding, so runway is unknown. With 2–10 people, it's either bootstrapped/consultancy-funded or quietly seed-funded.
  • Brand churn: Motia was wound down within about a year of its peak and the entity name is inconsistent (LLC vs Inc.).
  • No published business model yet. ELv2 plus a private cloud CLI suggests a hosted product that hasn't launched.
  • A crowded category (Temporal, Inngest, Trigger.dev, Restate, agent frameworks).

Questions to ask

  1. Have you raised? From whom, how much, and how many months of runway?
  2. Which is the operating entity, Motia LLC or III, Inc., and where is it incorporated? What's the equity structure (options vs LLC units)?
  3. What's the commercial product and timeline (iii cloud, enterprise licence)? Are there any paying users?
  4. Why wind down Motia instead of evolving it? What happened to its users?
  5. Team: how many full-time engineers, where are they, is FullStack involved, and who owns the Rust engine?
  6. How does the Elastic License affect contributors and customers?
